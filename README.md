a)  Реализация функции вычисления параметров прямоугольника (периметра, площади, диагонали): В данном репозитории в ветке rectangle загружен cpp-файл с программой на языке программирования С++. Программа принимает на вход введённые с клавиатуры значения длины и ширины прямоугольника (два вещественных числа, которые сохраняются в переменные double length, width непосредственно в функции int main()), и рассчитывает по ним заданные параметры. Всего в коде реализована одна функция: bool rectangleParams(double length, double width, double &perimeter, double &area, double &diagonal). Эта функция возвращает true (1), если оба значения сторон строго положительные, и false (0) в противном случае. Таким образом, она выполняет проверку введённых значений – определяет корректность сторон прямоугольника (они должны быть > 0). При успешной проверке функция вычисляет:
    1) периметр 2 * (length + width),
    2) площадь length * width,
    3) длину диагонали sqrt(length * length + width * width)
    4) записывает результаты в переменные, переданные по ссылке (тип double используется для работы с вещественными числами).
    В main() после вызова rectangleParams в зависимости от возвращённого значения либо выводятся рассчитанные параметры, либо выводится сообщение об ошибке «Стороны должны быть положительными». Для вычисления квадратного корня используется функция sqrt из библиотеки .
Задание выполнено Мороз Еленой.

b) Реализация функции вычисления параметров (периметра, площади, равнобедренности) треугольника):
В данном репозитории в ветке triangle загружен cpp-файл с программой на языке программирования С++. Программа принимает на вход введённые с клавиатуры значения, т.е. стороны треугольника (которые записываются в последовательном контейнере array<double, 3> sides, который реализуется уже в int main()), и расчитывает по ним заданные функциями параметры. Всего в коде 4 функции. Первая функция int Triangle(array<double, 3>& sides) возвращает в результате 1 (True) или 0 (False) и является по своей сути проверкой введенных значений (т.е. данная функция определяет существование треугольника со сторонами, которые вводит пользователь). Далее функции double Perimeter(array<double, 3>& sides) & double Square(array<double, 3>& sides) рассчитывают соответсвенно периметр и площадь треугольника по заданным значениям контейнера sides и возвращают их (использован тип double для работы с вещественными числами). Последняя функция void Isosceles(array<double, 3>& sides) ничего не возвращает, а лишь выводит результат проверки на равнобедренность. 
Задание выполнено Земелевой Ксенией.

c) Реализация функции вычисления параметров (трапеции, периметр, площадь, длины средней линии):
В данном репозитории в ветке trapezoid загружен cpp-файл с программой на языке программирования C++. Программа принимает на вход введённые с клавиатуры значения: верхнее основание a, нижнее основание b, боковые стороны c и d, высоту h (все переменные типа double). Все вычисления и проверки выполняются непосредственно в функции int main(). Программа последовательно выполняет три проверки корректности введённых данных: 
1) все ли числа положительные;
2) не превышает ли высота боковые стороны;
3) выполняется ли условие существования трапеции (сумма любых трёх сторон больше четвёртой).
При нарушении любого из условий программа выводит соответствующее сообщение об ошибке и завершается с кодом return 1. Если все проверки пройдены успешно, программа вычисляет периметр (a + b + c + d), площадь ((a + b) / 2 * h) и среднюю линию ((a + b) / 2) трапеции, после чего выводит результаты на экран. При успешном завершении программа возвращает 0 (return 0).
Задание выполнено Потаповой Алёной.

d) В данном репозитории в ветке circle загружен cpp-файл с программой на языке C++.
Программа принимает на вход введённые с клавиатуры значения: радиус окружности и угол кругового сектора в градусах (оба типа double). Вычисления реализованы в виде отдельной функции.
Функция bool circleParams(double radius, double angleDeg, double &circumference, double &areaCircle, double &areaSector):
возвращает true, если radius > 0 и угол angleDeg находится в диапазоне [0, 360], и false в противном случае;
при успешной проверке вычисляет: длину окружности 2 * π * radius,площадь круга π * radius²,площадь кругового сектора (π * radius² * angleDeg) / 360.0, и записывает результаты по ссылкам.
В функции main() организован цикл ввода с проверкой: радиус должен быть положительным, угол – от 0 до 360. После ввода вызывается circleParams. В зависимости от возвращённого значения либо выводятся рассчитанные параметры, либо сообщение об ошибке «Некорректные данные». Для числа π используется константа const double PI = acos(-1.0).
Задание выполнено Никитиной Викторией.
